Khi nhiều AWS account (ví dụ account của từng shop con) cần mount chung một thư mục, EFS vẫn đáp ứng được: bổ sung file system policy cấp quyền cho account còn lại, và kết nối mạng giữa hai VPC bằng VPC peering hoặc transit gateway.

<Takeaway>Block storage (EBS): ổ đĩa riêng của một instance trong một AZ, tính phí theo dung lượng cấp phát. File storage (EFS, FSx): nhiều instance dùng chung; EFS tự co giãn và tính theo dung lượng dữ liệu thực tế lưu trữ. Object storage (S3): truy cập qua API, S3 Standard lưu dữ liệu tại tối thiểu 3 AZ. S3 Standard và EFS Regional cùng được thiết kế cho độ bền 99.999999999% (11 số 9). So sánh chi phí cần dựa trên bảng giá hiện hành của từng Region, và lưu ý EBS tính phí theo dung lượng cấp phát kể cả phần chưa sử dụng.</Takeaway>

</Scene>

Cần IOPS ổn định cho database I/O lớn, trên 80.000 IOPS, hoặc Multi-Attach: io1/io2 (io2 Block Express tối đa 256.000 IOPS). Đọc tuần tự khối dữ liệu lớn: st1; dữ liệu ít truy cập: sc1; hai loại HDD không dùng được làm boot volume. Tạo môi trường test nhanh từ snapshot: fast snapshot restore.</Takeaway>

<Takeaway>EFS: file system NFS dùng chung giữa nhiều AZ. Cấu hình khuyến nghị: General Purpose performance mode + Elastic throughput; Max I/O là thế hệ trước. Đã biết trước nhu cầu throughput, không phụ thuộc dung lượng: Provisioned throughput. Tệp ít truy cập: lớp IA. Mount target cùng AZ để giảm độ trễ.</Takeaway>

<Scene id="s4" label="Phần 4/4" title="Lựa chọn file system cho bốn nhóm người dùng" questions={["exam2_q12", "exam2_q56", "exam1_q65", "exam3_q5", "exam3_q43", "exam3_q56", "exam1_q24", "exam3_q61", "exam3_q26"]}>

Ngoài EFS, AWS cung cấp ba loại **FSx** cho các nhu cầu chuyên biệt. Mỗi nhóm trong bốn nhóm người dùng của ShopViet có ba yêu cầu bắt buộc. Thử mount từng file system cho từng nhóm để xác định file system đáp ứng đầy đủ yêu cầu:

<FsxSim client:visible />

Khi văn phòng cần duy trì file share SMB tại chỗ nhưng lưu dữ liệu trên S3, sử dụng **S3 File Gateway** (xem bài Storage Gateway).

<Takeaway>Windows, SMB, NTFS, Active Directory, DFS: FSx for Windows File Server. HPC, đọc song song, nạp dữ liệu từ S3: FSx for Lustre. Đang sử dụng NetApp, cần NFS + SMB + iSCSI: FSx for NetApp ONTAP. Thư mục dùng chung đơn giản cho Linux: EFS.</Takeaway>

</Scene>
