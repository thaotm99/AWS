<Takeaway>Cần audit hoặc tự kiểm soát key: SSE-KMS. Cần xoay vòng hằng năm: customer managed key + automatic rotation. Giảm phí KMS: S3 Bucket Keys. Nhiều Region cùng key: multi-Region keys. Mỗi object một key, đơn giản nhất: SSE-S3.</Takeaway>
