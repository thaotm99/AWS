<Scene id="s1" label="Phần 1/2" title="Xác thực khách hàng: Cognito user pool và identity pool" questions={["exam2_q17", "exam6_q50"]}>

**User pool** là thư mục người dùng: cung cấp chức năng đăng ký, đăng nhập và trả về token (JWT). **Identity pool** đổi danh tính đã xác thực thành **temporary AWS credentials** để gọi trực tiếp các dịch vụ AWS như S3. ShopViet có cả hai yêu cầu này. Chọn tình huống và so sánh hai phương án:

<Scene id="s2" label="Phần 2/2" title="Xác thực nhân viên, Active Directory và đối tác" questions={["exam6_q10", "exam4_q4", "exam1_q10", "exam3_q28", "exam6_q44", "exam3_q5", "exam2_q4"]}>

Cognito phục vụ khách hàng của ứng dụng. Nhân viên và đối tác có các yêu cầu khác: single sign-on vào nhiều AWS account, tái sử dụng tài khoản Active Directory on-premises, truy cập file share và truyền tệp qua SFTP. Chọn từng tình huống, thay đổi cấu hình, sau đó nhấn Đăng nhập.

<StaffSignInSim client:visible />

<Takeaway>Nhân viên truy cập nhiều account: IAM Identity Center + permission sets. Chỉ sử dụng AD on-premises để xác thực: AD Connector. AD chạy trên AWS và có trust với AD on-premises: AWS Managed Microsoft AD. File share với quyền NTFS: FSx for Windows File Server. Đối tác truyền tệp qua SFTP: AWS Transfer Family.</Takeaway>

</Scene>
