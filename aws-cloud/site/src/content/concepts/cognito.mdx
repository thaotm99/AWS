**User pool** là danh bạ người dùng: đăng ký, đăng nhập, trả về token (JWT). **Identity pool** đổi danh tính đã đăng nhập thành **credentials AWS tạm thời** để gọi thẳng dịch vụ AWS như S3. ShopViet gặp cả hai việc. Chọn tình huống rồi so sánh hai cách làm:

<Scene id="s2" label="Cảnh 2/2" title="Nhân viên, Active Directory và đối tác" questions={["exam6_q10", "exam4_q4", "exam1_q10", "exam3_q28", "exam6_q44", "exam3_q5", "exam2_q4"]}>

Cognito dành cho khách hàng. Nhân viên và đối tác cần công cụ khác: đăng nhập một lần vào nhiều AWS account, dùng lại tài khoản Active Directory ở văn phòng, mở ổ chia sẻ, gửi file qua SFTP. Chọn từng tình huống, bật tắt công tắc, rồi bấm Đăng nhập.

<StaffSignInSim client:visible />

<Takeaway>Nhân viên vào nhiều account: IAM Identity Center + permission sets. Chỉ cần mượn AD ở văn phòng: AD Connector. Cần AD chạy trên AWS và trust với văn phòng: AWS Managed Microsoft AD. Ổ chia sẻ có quyền NTFS: FSx for Windows File Server. Đối tác gửi file qua SFTP: Transfer Family.</Takeaway>

</Scene>
