<Scene id="s3" label="Cảnh 3/4" title="Một request đi qua CloudFront như thế nào?" questions={["exam6_q62", "exam1_q38", "exam4_q63", "exam5_q15", "exam5_q13", "exam5_q57"]}>

Mỗi request của khách đi qua một chuỗi trạm ngay tại edge location gần họ, trước khi tới server của ShopViet. Mỗi trạm giải quyết một việc: chứng chỉ HTTPS, chặn tấn công, chặn theo quốc gia, kiểm tra quyền xem nội dung trả phí, mã hoá dữ liệu nhạy cảm, và chọn origin. Chọn một tình huống, bật tắt công tắc, rồi gửi request để xem trạm nào xử lý.

<EdgePipelineSim client:visible />

<Takeaway>Chặn tấn công: AWS WAF. Chặn theo quốc gia: geo restriction. Nội dung trả phí: signed URL (một file) hoặc signed cookie (nhiều file). Dữ liệu nhạy cảm: field-level encryption. Chia theo đường dẫn: cache behavior. Dự phòng origin: origin group. Tên miền riêng: chứng chỉ ACM ở us-east-1.</Takeaway>

</Scene>

<Scene id="s4" label="Cảnh 4/4" title="CloudFront, S3 Transfer Acceleration hay Global Accelerator?" questions={["exam5_q21", "exam6_q58", "exam1_q59", "exam3_q8", "exam4_q58", "exam5_q55", "exam2_q22"]}>

Ba dịch vụ cùng dùng edge location của AWS nhưng giải quyết ba việc khác nhau. Bài Global Infrastructure đã có mô phỏng failover của Global Accelerator; ở đây là cách chọn theo nhu cầu.

<RequirementPicker client:visible items={[
  { need: "Cache trang, ảnh, video cho người xem ở xa", answer: "CloudFront", why: "Chỉ HTTP/HTTPS, có cache tại edge." },
  { need: "Upload file lớn vào S3 từ khắp nơi", answer: "S3 Transfer Acceleration", why: "Đi vào edge gần người upload rồi chạy trên mạng AWS tới bucket." },
  { need: "Game, ứng dụng dùng UDP", answer: "Global Accelerator", why: "Hỗ trợ TCP và UDP; CloudFront thì không." },
  { need: "Khách hàng cần whitelist vài IP cố định", answer: "Global Accelerator", why: "2 IP tĩnh anycast đứng trước ALB/NLB ở nhiều Region." },
  { need: "Failover tự động giữa Region, không chờ DNS", answer: "Global Accelerator", why: "Chuyển sang endpoint khỏe mà client không cần phân giải DNS lại." },
]} />

<Takeaway>Cần cache nội dung web: CloudFront. Cần tăng tốc upload vào S3: Transfer Acceleration. Cần UDP, IP tĩnh hoặc failover giữa Region: Global Accelerator.</Takeaway>

</Scene>
