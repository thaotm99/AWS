<Scene id="s2" label="Phần 2/4" title="Các loại origin của CloudFront" questions={["exam1_q62", "exam6_q5", "exam3_q40", "exam2_q2", "exam3_q42", "exam3_q48", "exam1_q1"]}>

Cơ chế cache tại edge: request đầu tiên (cache miss) được chuyển tới origin; các request tiếp theo trong thời gian TTL (cache hit) được phục vụ trực tiếp tại edge location.

<Scene id="s3" label="Phần 3/4" title="Quy trình xử lý request tại edge location" questions={["exam6_q62", "exam1_q38", "exam4_q63", "exam5_q15", "exam5_q13", "exam5_q57"]}>

Trước khi được chuyển tới origin, mỗi request đi qua chuỗi bước xử lý tại edge location: TLS termination với chứng chỉ ACM, đánh giá bởi AWS WAF, geo restriction, xác thực signed URL/cookie, field-level encryption và lựa chọn origin theo cache behavior. Chọn một tình huống, thay đổi cấu hình và gửi request để quan sát bước xử lý tương ứng.

<EdgePipelineSim client:visible />

<Takeaway>Lọc tấn công tầng ứng dụng: AWS WAF. Giới hạn theo quốc gia: geo restriction. Nội dung riêng tư: signed URL (một object) hoặc signed cookie (nhiều object). Dữ liệu nhạy cảm: field-level encryption. Định tuyến theo path: cache behavior. Dự phòng origin: origin group. Tên miền tuỳ chỉnh: chứng chỉ ACM tại us-east-1.</Takeaway>

</Scene>

<Scene id="s4" label="Phần 4/4" title="CloudFront, S3 Transfer Acceleration và AWS Global Accelerator" questions={["exam5_q21", "exam6_q58", "exam1_q59", "exam3_q8", "exam4_q58", "exam5_q55", "exam2_q22"]}>

Ba dịch vụ cùng sử dụng mạng edge của AWS nhưng phục vụ các mục đích khác nhau. Cơ chế failover của Global Accelerator đã được trình bày trong bài Global Infrastructure; phần này tổng hợp tiêu chí lựa chọn theo yêu cầu.

<RequirementPicker client:visible items={[
  { need: "Cache nội dung web (trang, ảnh, video) cho người dùng ở xa", answer: "CloudFront", why: "Hỗ trợ HTTP/HTTPS, có cache tại edge." },
  { need: "Tải lên tệp dung lượng lớn vào S3 từ nhiều khu vực địa lý", answer: "S3 Transfer Acceleration", why: "Dữ liệu đi vào edge location gần nhất, sau đó truyền qua mạng backbone của AWS tới bucket." },
  { need: "Ứng dụng game hoặc ứng dụng sử dụng giao thức UDP", answer: "Global Accelerator", why: "Hỗ trợ TCP và UDP; CloudFront chỉ hỗ trợ HTTP/HTTPS." },
  { need: "Đối tác yêu cầu allow-list một số địa chỉ IP cố định", answer: "Global Accelerator", why: "Cung cấp hai địa chỉ IP tĩnh anycast đứng trước ALB/NLB tại nhiều Region." },
  { need: "Failover tự động giữa các Region, không phụ thuộc DNS TTL", answer: "Global Accelerator", why: "Chuyển traffic sang endpoint healthy mà client không cần phân giải DNS lại." },
]} />

<Takeaway>Cache nội dung web: CloudFront. Tăng tốc tải lên S3: S3 Transfer Acceleration. Giao thức UDP, địa chỉ IP tĩnh hoặc failover giữa các Region: AWS Global Accelerator.</Takeaway>

</Scene>
