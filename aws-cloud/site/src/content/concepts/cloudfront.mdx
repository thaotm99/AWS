<Scene id="s4" label="Cảnh 4/4" title="CloudFront, S3 Transfer Acceleration hay Global Accelerator?" questions={["exam5_q21", "exam6_q58", "exam1_q59", "exam3_q8", "exam4_q58", "exam5_q55", "exam2_q22"]}>

Ba dịch vụ cùng dùng edge location của AWS. Bài Global Infrastructure đã có mô phỏng failover của Global Accelerator; ở đây là cách phân biệt nhanh khi đọc đề.

<RequirementPicker client:visible items={[
  { need: "Cache trang, ảnh, video cho người xem ở xa", answer: "CloudFront", why: "Chỉ HTTP/HTTPS, có cache tại edge.", refs: ["exam6_q58"] },
  { need: "Upload file lớn vào S3 từ khắp nơi", answer: "S3 Transfer Acceleration", why: "Đi vào edge gần người upload rồi chạy trên mạng AWS tới bucket.", refs: ["exam6_q58", "exam5_q21"] },
  { need: "Game, ứng dụng dùng UDP", answer: "Global Accelerator", why: "Hỗ trợ TCP và UDP; CloudFront thì không.", refs: ["exam1_q59", "exam3_q8"] },
  { need: "Khách hàng cần whitelist vài IP cố định", answer: "Global Accelerator", why: "2 IP tĩnh anycast đứng trước ALB/NLB ở nhiều Region.", refs: ["exam4_q58"] },
  { need: "Failover tự động giữa Region, không chờ DNS", answer: "Global Accelerator", why: "Chuyển sang endpoint khỏe mà client không cần phân giải DNS lại.", refs: ["exam5_q55", "exam2_q22"] },
]} />

<Takeaway>Có chữ cache hoặc HTTP: CloudFront. Có chữ upload vào S3: Transfer Acceleration. Có chữ UDP, IP tĩnh, failover giữa Region: Global Accelerator.</Takeaway>

</Scene>
