<Scene id="s2" label="Phần 2/3" title="Vận hành Lambda trong môi trường production" questions={["exam4_q25", "exam1_q50", "exam3_q20", "exam6_q35", "exam4_q39", "exam2_q16"]}>

Một số vấn đề chỉ xuất hiện khi triển khai lên production: function gắn vào VPC không truy cập được Internet, người dùng chờ lâu vào giờ cao điểm, thông báo bị mất, mật khẩu database lưu trong cấu hình. Chọn từng tình huống, chạy thử, sau đó bật tuỳ chọn để khắc phục:

<LambdaRunSim client:visible />

Hai lưu ý bổ sung. Mỗi lần thực thi Lambda tối đa **15 phút**; job dài hơn nên chạy bằng container trên Fargate (bài Containers). Khi nhiều function dùng chung thư viện, đóng gói thư viện đó thành **Lambda Layers**.

<Takeaway>Lambda trong VPC cần NAT gateway để truy cập Internet. Cold start vào giờ cao điểm: provisioned concurrency. Concurrency có quota theo account và Region; cấu hình alarm trên ConcurrentExecutions. Không lưu mật khẩu: IAM database authentication. Truy cập cross-account: cả execution role và bucket policy đều phải cho phép.</Takeaway>

</Scene>

<Scene id="s3" label="Phần 3/3" title="Cung cấp API cho ứng dụng và đối tác" questions={["exam1_q49", "exam3_q52", "exam3_q53", "exam2_q58", "exam4_q44", "exam5_q32", "exam1_q57", "exam1_q11"]}>

Ứng dụng mobile, đối tác bán hàng và trang quản trị đều gọi tới `api.shopviet.vn`. **API Gateway** thực hiện một chuỗi bước kiểm tra trước khi request tới mã ứng dụng. Chọn tình huống và gửi request:

<ApiGatewaySim client:visible />

Một số yêu cầu khác:

- Chat giữa người mua và người bán cần kết nối hai chiều, máy chủ chủ động đẩy tin nhắn tới client: **WebSocket API**. Với REST API, mỗi request độc lập và không duy trì kết nối.
- Shipper gửi vị trí liên tục để theo dõi đơn hàng: API Gateway tiếp nhận dữ liệu và đẩy vào Kinesis để **Kinesis Data Analytics** phân tích stream.
- Tiếp nhận giao dịch từ ứng dụng, kiểm tra dữ liệu đơn giản rồi xử lý, với chi phí vận hành thấp nhất: **REST API + Lambda** kiểm tra dữ liệu, backend serverless phía sau. Không có máy chủ hay container nào cần vá lỗi.

<Takeaway>Giới hạn truy cập theo dải IP nội bộ: resource policy. Xác thực JWT không cần viết mã: HTTP API với JWT authorizer. Giới hạn theo từng client: usage plan + API key. Giảm tải backend khi request lặp lại: caching. Tác vụ xử lý lâu: API Gateway đẩy vào SQS. Giao tiếp hai chiều: WebSocket API.</Takeaway>

</Scene>
