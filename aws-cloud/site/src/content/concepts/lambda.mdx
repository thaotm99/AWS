<Scene id="s2" label="Cảnh 2/3" title="Khi Lambda chạy thật" questions={["exam4_q25", "exam1_q50", "exam3_q20", "exam6_q35", "exam4_q39", "exam2_q16"]}>

Chạy thử trên máy thì ổn, lên production mới lộ chuyện: function gắn vào VPC rồi không ra được internet, khách chờ lâu lúc cao điểm, thông báo bị rơi, mật khẩu database nằm trong cấu hình. Chọn từng chuyện, chạy thử, rồi bật công tắc để sửa:

<LambdaRunSim client:visible />

Hai điều nữa. Một lần chạy Lambda tối đa **15 phút**; job dài hơn thì chạy container trên Fargate (bài Containers). Nhiều function dùng chung thư viện thì đóng gói thư viện đó thành **Lambda Layers**.

<Takeaway>Lambda trong VPC cần NAT gateway để ra internet. Cold start lúc cao điểm: provisioned concurrency. Concurrency có quota theo account và Region; đặt alarm trên ConcurrentExecutions. Không lưu mật khẩu: IAM database authentication. Truy cập chéo account: cả execution role lẫn bucket policy phải cho phép.</Takeaway>

</Scene>

<Scene id="s3" label="Cảnh 3/3" title="Mở API cho app và đối tác" questions={["exam1_q49", "exam3_q52", "exam3_q53", "exam2_q58", "exam4_q44", "exam5_q32", "exam1_q57", "exam1_q11"]}>

App di động, đối tác bán hàng và trang quản trị đều gọi vào `api.shopviet.vn`. **API Gateway** chạy một loạt kiểm tra trước khi tới code của bạn. Chọn tình huống và gửi request:

<ApiGatewaySim client:visible />

Còn vài nhu cầu khác:

- Chat giữa khách và người bán cần kết nối hai chiều, server tự đẩy tin nhắn xuống: **WebSocket API**. REST API thì mỗi request độc lập, không giữ kết nối.
- Shipper gửi vị trí liên tục để theo dõi đơn: API Gateway nhận dữ liệu, đẩy vào Kinesis để **Kinesis Data Analytics** phân tích stream.
- Nhận giao dịch từ app, kiểm tra nhẹ rồi xử lý, ít vận hành nhất: **REST API + Lambda** kiểm tra dữ liệu, backend serverless phía sau. Không có server hay container nào phải vá.

<Takeaway>Chỉ cho dải IP nội bộ: resource policy. JWT mà không viết code: HTTP API với JWT authorizer. Giới hạn theo từng khách: usage plan + API key. Giảm tải backend khi request lặp lại: caching. Việc chậm: API Gateway đẩy vào SQS. Chat hai chiều: WebSocket API.</Takeaway>

</Scene>
