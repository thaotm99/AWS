    why: "DataSync làm đợt chuyển lớn; File Gateway cho ứng dụng tại kho tiếp tục làm việc với dữ liệu đã nằm trên S3." },

<Takeaway>Mạng đủ nhanh: DataSync (đi riêng qua Direct Connect + VPC endpoint được). Quá nhiều dữ liệu cho đường truyền: Snowball, nhập vào S3 rồi lifecycle hoặc chép tiếp. SFTP: Transfer Family. Object có sẵn sang Region khác: S3 Batch Replication.</Takeaway>

</Scene>
