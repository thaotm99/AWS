ShopViet càng lớn, database càng gặp nhiều chuyện: báo cáo làm chậm web, Lambda mở quá nhiều kết nối, ổ đĩa đầy, cả Region gặp sự cố. Chọn từng sự cố, chạy để thấy hậu quả, rồi bật tính năng RDS tương ứng và chạy lại:

<RdsOpsSim client:visible />

Hai việc nữa giúp đội vận hành ngủ ngon. Hệ thống kế toán chạy SQL Server thì dùng **RDS for SQL Server Multi-AZ**: AWS lo standby và failover. Và để mọi database mới đều đúng chuẩn (Multi-AZ, backup, mã hoá), tạo chúng từ cùng một **template CloudFormation** đã được kiểm tra.

<Takeaway>Báo cáo làm chậm web: Read Replica cùng Region (không tính phí replication). Quá nhiều kết nối: RDS Proxy. Ổ đĩa có thể đầy: storage auto scaling. Region hỏng: cross-Region Read Replica + copy backup sang Region khác. Cần vào OS: RDS Custom.</Takeaway>

</Scene>
