WAF chỉ lọc request web. Nhiều chuyện xấu khác xảy ra **bên trong** account: một server bị chiếm, một file nhạy cảm để sai chỗ, một account mới quên cấu hình. Chọn một sự cố, thử bật và tắt dịch vụ tương ứng, rồi cho sự cố xảy ra.

<IncidentSim client:visible />

<Takeaway>DDoS lớn, cần đội AWS hỗ trợ và báo cáo: Shield Advanced. Server bị chiếm, đào coin: GuardDuty. Lỗ hổng phần mềm trên EC2: Inspector. Dữ liệu cá nhân trong S3: Macie. Rule giống nhau cho nhiều account: Firewall Manager. Gom log bảo mật: Security Lake.</Takeaway>

</Scene>
