Đề hay đặt các dịch vụ này làm đáp án nhiễu cho nhau. Chọn yêu cầu để xem đề chọn dịch vụ nào:

<RequirementPicker client:visible items={[
  { need: "Chống DDoS chủ động, có đội AWS hỗ trợ khi bị tấn công, có báo cáo", answer: "AWS Shield Advanced",
    why: "Shield Advanced bảo vệ DDoS nâng cao, có DDoS Response Team (DRT), báo cáo và log chi tiết. Shield Standard miễn phí nhưng không có các phần này." },
  { need: "Quản lý tập trung rule bảo mật cho nhiều account", answer: "AWS Firewall Manager",
    why: "Áp rule cho AWS WAF, Shield Advanced và security group trên toàn Organizations." },
  { need: "Phát hiện hoạt động độc hại (S3, EC2 bị dùng đào coin)", answer: "Amazon GuardDuty",
    why: "Phân tích log (CloudTrail, VPC Flow Logs, DNS) để phát hiện mối đe dọa." },
  { need: "Tìm lỗ hổng phần mềm trên EC2", answer: "Amazon Inspector",
    why: "Quét lỗ hổng và mức độ phơi nhiễm của workload." },
  { need: "Tìm dữ liệu nhạy cảm (thông tin cá nhân) trong S3", answer: "Amazon Macie",
    why: "Dùng machine learning để phát hiện và phân loại dữ liệu nhạy cảm trên S3." },
  { need: "Gom log bảo mật từ nhiều account và nguồn vào một chỗ, ít code", answer: "Amazon Security Lake",
    why: "Tự thu thập log và sự kiện bảo mật thành data lake trên S3." },
]} />

<Takeaway>WAF: lọc request web. Shield Advanced: DDoS + DRT. Firewall Manager: quản lý rule tập trung. GuardDuty: phát hiện đe dọa. Inspector: lỗ hổng EC2. Macie: dữ liệu nhạy cảm S3. Security Lake: gom log bảo mật.</Takeaway>

</Scene>
