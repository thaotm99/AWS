<Scene id="s1" label="Phần 1/3" title="AWS WAF: lọc request độc hại trước khi tới ứng dụng" questions={["exam5_q13", "exam1_q6", "exam5_q45", "exam2_q30", "exam6_q60", "exam5_q57", "exam2_q32"]}>

<p class="scene-intro">Một phần traffic tới website là traffic độc hại; một web application firewall đặt trước ứng dụng có thể chặn các request này trước khi chúng tới ứng dụng.</p>

Sáu loại request đang được gửi tới MFTECH, trong đó có một đối tác vận chuyển hợp lệ gọi từ nước ngoài bằng IP cố định. Kích hoạt từng rule, chọn tài nguyên liên kết với AWS WAF, sau đó gửi request.

AWS WAF đánh giá các rule trong web ACL theo **priority** từ số nhỏ nhất trở lên, cho tới khi gặp một rule khớp có terminating action (Allow hoặc Block) hoặc đã xét hết rule. Vì vậy, khi chặn theo quốc gia bằng geo match nhưng vẫn cần cho phép một số IP của đối tác, MFTECH đặt rule IP set chứa các IP đó với action Allow ở priority nhỏ hơn rule geo match: request của đối tác được cho phép ngay và không còn được đánh giá bởi rule geo match.

<WafSim client:visible />

<Takeaway>SQL injection, XSS: managed rule. Giới hạn theo quốc gia: geo match. Một IP độc hại: IP set với action Block. Ngoại lệ cho IP đối tác trong một quốc gia bị chặn: IP set với action Allow, priority nhỏ hơn rule geo match. Request với tần suất bất thường: rate-based rule (evaluation window 1, 2, 5 hoặc 10 phút, mặc định 5 phút; ngưỡng tối thiểu 10 request). AWS WAF được liên kết với CloudFront, ALB, API Gateway REST API và một số dịch vụ khác (AppSync, Cognito, App Runner, Verified Access, Amplify), không gắn trực tiếp vào EC2. AWS WAF chỉ kiểm tra request **HTTP và HTTPS**; traffic SFTP (SSH) tới endpoint AWS Transfer Family không đi qua AWS WAF, nên giới hạn IP nguồn cho SFTP được thực hiện bằng security group của VPC hosted endpoint.</Takeaway>

</Scene>

<Scene id="s2" label="Phần 2/3" title="Sáu sự cố bảo mật và dịch vụ tương ứng" questions={["exam3_q58", "exam6_q4", "exam1_q36", "exam3_q1", "exam6_q14", "exam2_q44"]}>

<p class="scene-intro">Không phải mọi sự cố bảo mật đều đến từ request web; nhiều sự cố xảy ra bên trong AWS account, và mỗi loại sự cố có một dịch vụ chuyên phát hiện hoặc ngăn chặn.</p>

AWS WAF chỉ lọc request web. Nhiều sự cố khác xảy ra **bên trong** account: một EC2 instance bị chiếm quyền (compromised), một tệp nhạy cảm bị lưu sai vị trí, một account mới thiếu cấu hình. Chọn một sự cố, bật hoặc tắt dịch vụ tương ứng, sau đó mô phỏng sự cố.

<IncidentSim client:visible />

<Takeaway>DDoS quy mô lớn, cần hỗ trợ từ Shield Response Team (SRT) và báo cáo: AWS Shield Advanced. EC2 instance bị chiếm quyền, đào tiền mã hoá: Amazon GuardDuty. Lỗ hổng phần mềm trên EC2 instance: Amazon Inspector. Dữ liệu cá nhân trong S3: Amazon Macie. Áp dụng rule thống nhất cho nhiều account: AWS Firewall Manager. Tập trung log bảo mật: Amazon Security Lake.</Takeaway>

</Scene>
