<Scene id="s1" label="Phần 1/2" title="AWS WAF: lọc request độc hại trước khi tới ứng dụng" questions={["exam5_q13", "exam1_q6", "exam5_q45", "exam2_q30", "exam6_q60", "exam5_q57", "exam2_q32"]}>

Năm loại request đang được gửi tới ShopViet. Kích hoạt từng rule, chọn tài nguyên liên kết với AWS WAF, sau đó gửi request.

<WafSim client:visible />

<Takeaway>SQL injection, XSS: managed rule. Giới hạn theo quốc gia: geo match. Một IP độc hại: IP set. Request với tần suất bất thường: rate-based rule (evaluation window 1, 2, 5 hoặc 10 phút, mặc định 5 phút; ngưỡng tối thiểu 10 request). AWS WAF được liên kết với CloudFront, ALB, API Gateway REST API và một số dịch vụ khác (AppSync, Cognito, App Runner, Verified Access, Amplify), không gắn trực tiếp vào EC2.</Takeaway>

</Scene>

<Scene id="s2" label="Phần 2/2" title="Sáu sự cố bảo mật và dịch vụ tương ứng" questions={["exam3_q58", "exam6_q4", "exam1_q36", "exam3_q1", "exam6_q14", "exam2_q44"]}>

AWS WAF chỉ lọc request web. Nhiều sự cố khác xảy ra **bên trong** account: một server bị chiếm quyền, một tệp nhạy cảm bị lưu sai vị trí, một account mới thiếu cấu hình. Chọn một sự cố, bật hoặc tắt dịch vụ tương ứng, sau đó mô phỏng sự cố.

<IncidentSim client:visible />

<Takeaway>DDoS quy mô lớn, cần hỗ trợ từ đội ngũ AWS và báo cáo: Shield Advanced. Server bị chiếm quyền, đào tiền mã hoá: GuardDuty. Lỗ hổng phần mềm trên EC2: Inspector. Dữ liệu cá nhân trong S3: Macie. Áp dụng rule thống nhất cho nhiều account: Firewall Manager. Tập trung log bảo mật: Security Lake.</Takeaway>

</Scene>
