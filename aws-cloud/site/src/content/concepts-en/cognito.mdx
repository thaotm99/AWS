<Scene id="en-s1" label="Part 1/3" title="Authenticating customers: Cognito user pools and identity pools" questions={["exam2_q17", "exam6_q50"]}>

<p class="scene-intro">An application must know who the customer is before showing orders or accepting uploads; sign-up, sign-in and temporary access can be handed to a managed service instead of being built from scratch.</p>

A **user pool** is a user directory: it provides sign-up and sign-in and returns tokens (JWTs). An **identity pool** exchanges an authenticated identity for **temporary AWS credentials** to call AWS services such as S3 directly. ShopViet has both requirements. Pick a scenario and compare the two options:

<Scene id="en-s2" label="Part 2/3" title="Authenticating employees, Active Directory and partners" questions={["exam6_q10", "exam4_q4", "exam1_q10", "exam3_q28", "exam6_q44", "exam3_q5", "exam2_q4"]}>

<p class="scene-intro">Employees and partners already have identities in the company's directory or identity provider; the goal is to reuse those identities instead of creating a new set of sign-in credentials on AWS.</p>

Cognito serves the application's customers. Employees and partners have different requirements: single sign-on into multiple AWS accounts, reusing identities in the on-premises Active Directory, accessing file shares, and transferring files over SFTP. Pick each scenario, change the configuration, then press Sign in.

<StaffSignInSim client:visible />

<Takeaway>Employees accessing multiple accounts: IAM Identity Center + permission sets. Use on-premises AD for authentication without synchronizing the directory to AWS: AD Connector. AD running on AWS with a trust to on-premises AD: AWS Managed Microsoft AD. File share with NTFS permissions: FSx for Windows File Server. Partners transferring files over SFTP: AWS Transfer Family.</Takeaway>

</Scene>

<Scene id="en-s3" label="Part 3/3" title="Quick comparison: directory options that are easy to confuse" questions={["exam3_q28"]}>

<p class="scene-intro">Several user-directory services have similar names; each serves a different group of users and a different kind of integration.</p>

ShopViet's accounting application runs SQL Server on AWS and needs an Active Directory domain on AWS with a **trust** to the on-premises AD, so employees get single sign-on to resources in either domain. The right option is AWS Managed Microsoft AD (Part 2). The options below also carry the word "directory" or "AD" but do not meet this requirement. Select each item to see what it is for.

<Takeaway>A domain on AWS with a trust to the on-premises AD, AD-aware workloads (SQL Server): AWS Managed Microsoft AD.
