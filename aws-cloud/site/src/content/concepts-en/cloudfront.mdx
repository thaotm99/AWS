<Scene id="en-s3" label="Part 3/4" title="How a request is processed at the edge location" questions={["exam6_q62", "exam1_q38", "exam4_q63", "exam5_q15", "exam5_q13", "exam5_q57"]}>

Before forwarding a request to the origin, CloudFront can apply the following mechanisms at the edge location: TLS termination with an ACM certificate, evaluation by AWS WAF, geo restriction, signed URL/cookie validation, field-level encryption and origin selection by cache behavior. The simulation arranges these mechanisms into a chain for illustration. Choose a scenario, change the configuration and send a request to see the corresponding processing step.

<EdgePipelineSim client:visible />

<Takeaway>Filtering application-layer attacks: AWS WAF. Restricting by country: geo restriction. Private content: signed URL (one object) or signed cookie (many objects). Sensitive data: field-level encryption. Path-based routing: cache behavior. Origin redundancy: origin group. Custom domain name: ACM certificate in us-east-1.</Takeaway>

</Scene>

<Scene id="en-s4" label="Part 4/4" title="CloudFront, S3 Transfer Acceleration and AWS Global Accelerator" questions={["exam5_q21", "exam6_q58", "exam1_q59", "exam3_q8", "exam4_q58", "exam5_q55", "exam2_q22"]}>

The three services all use the AWS edge network but serve different purposes. Global Accelerator failover was covered in the Global Infrastructure lesson; this part summarizes the selection criteria by requirement.

<RequirementPicker client:visible items={[
  { need: "Cache web content (pages, images, video) for distant users", answer: "CloudFront", why: "Supports HTTP/HTTPS, with caching at the edge." },
  { need: "Upload large files to S3 from many geographic regions", answer: "S3 Transfer Acceleration", why: "Data enters the nearest edge location, then is routed to the bucket over an AWS-optimized network path. Transfer Acceleration speeds up transfers both to and from the bucket but does not cache." },
  { need: "A game or an application that uses the UDP protocol", answer: "Global Accelerator", why: "Global Accelerator listeners support TCP and UDP; CloudFront distributes content over HTTP/HTTPS (including WebSocket and gRPC)." },
  { need: "A partner requires allow-listing a few fixed IP addresses", answer: "Global Accelerator", why: "Provides two static anycast IPv4 addresses (dual-stack: two additional IPv6 addresses) in front of ALB/NLB/EC2 in multiple Regions." },
  { need: "Automatic failover between Regions, independent of DNS TTL", answer: "Global Accelerator", why: "Shifts traffic to a healthy endpoint without clients having to resolve DNS again." },
]} />

<Takeaway>Caching web content: CloudFront. Accelerating long-distance transfers to/from an S3 bucket (typically centralized uploads): S3 Transfer Acceleration. UDP, static IP addresses or failover between Regions: AWS Global Accelerator.</Takeaway>

</Scene>
