<Scene id="en-s1" label="Part 1/4" title="Controlling AWS costs" questions={["exam6_q22", "exam6_q1", "exam4_q30"]}>

Each cost management tool answers a different question:

- **Cost Explorer**: where are the costs coming from? Shows charts and filters by service and by account.
- **AWS Budgets**: alerts when costs are about to exceed the budget. Set thresholds for actual cost, forecasted cost, usage, or for the **coverage** and **utilization** of Reserved Instances and Savings Plans; notifications go out by email or SNS. A **budget action** can be attached (apply an IAM policy, apply an SCP, or target specific EC2/RDS instances), running automatically or after approval; several actions can be attached to the same threshold. Budgets data is updated up to three times a day.
- **Cost Optimization Hub**: where should costs be cut? Consolidates savings recommendations (rightsizing, deleting idle resources, Savings Plans, Reserved Instances) across accounts and Regions in one place.
- **Compute Optimizer**: which resource size is right? Recommends suitable configurations for EC2 instances, Auto Scaling groups, EBS volumes, Lambda functions, ECS services on Fargate and other resources.

Choose a ShopViet problem, choose a tool, then run the simulation for one month:

<CostWatchSim client:visible />

<Takeaway>Alerting and automatic action when the budget is exceeded: AWS Budgets with alerts and budget actions (apply an IAM policy, apply an SCP, or target specific EC2/RDS instances; each action is one type, and several actions can be set for the same threshold). Tracking Savings Plans coverage: a Savings Plans coverage budget in AWS Budgets. Identifying unused and oversized resources: Cost Optimization Hub combined with Compute Optimizer. Cost Explorer is for viewing and analyzing costs; alerts on budget thresholds are the job of AWS Budgets.</Takeaway>

<Scene id="en-s2" label="Part 2/4" title="Choosing the type of long-term usage commitment" questions={["exam6_q38"]}>

After the launch, ShopViet's load has stabilized. Committing to a fixed amount of spend per hour for 1 or 3 years in exchange for prices lower than on-demand: that is **Savings Plans**. AWS currently offers four types:

- **Compute Savings Plans**: the most flexible, up to 66% off on-demand. Apply to EC2 (any instance family, size, OS, tenancy, Region), Fargate and Lambda.
- **EC2 Instance Savings Plans**: up to 72% off, but only for one instance family in one Region.
- **Database Savings Plans**: up to 35% off database services such as Aurora, RDS, DynamoDB, ElastiCache, DocumentDB, Neptune, Keyspaces, Timestream, DMS and OpenSearch Service.
- **SageMaker AI Savings Plans**: up to 64% off, exclusively for SageMaker AI instances.

ShopViet's requirement: every workload gets a discount, with the fewest plans possible for easy management:

<SavingsPlanSim client:visible />

<Takeaway>EC2 + Fargate + Lambda: one Compute Savings Plan. SageMaker is outside the scope of Compute Savings Plans and needs SageMaker AI Savings Plans; databases have their own Database Savings Plans. EC2 Instance Savings Plans fit only when you are certain to use one instance family in one Region.</Takeaway>

</Scene>

<Scene id="en-s3" label="Part 3/4" title="Processing text and speech without an ML team" questions={["exam1_q4", "exam2_q26", "exam5_q32", "exam5_q58"]}>

AWS provides pre-trained AI services that you use through API calls, with no machine learning knowledge required:

- **Amazon Comprehend**: analyzes **text**: sentiment, entities, key phrases. Supports **custom entity recognition** to identify entity types specific to the business. Comprehend supports only certain languages (English, Spanish, French, German, Italian, Portuguese, Japanese, Korean, Hindi, Arabic, Chinese); Vietnamese is not yet on the list.
- **Amazon Transcribe**: converts **speech** to text and can separate individual speakers.
- **Amazon Textract**: extracts text, tables and forms from **scanned images and PDFs**; recognizes text in English, French, German, Italian, Portuguese and Spanish.

Training your own model on SageMaker also meets these requirements, but it needs staff with ML expertise and costs more to operate. When a suitable pre-trained service exists, prefer that service.

<Takeaway>Text → sentiment, entities: Comprehend (custom entity types: custom entity recognition). Speech → text: Transcribe, then query with SQL using Athena. Scanned images, PDFs → text: Textract, then pass to Comprehend. Traffic spikes: put SQS between API Gateway and Lambda; automatically delete data after one year: DynamoDB TTL (expired items are typically deleted within a few days).</Takeaway>
