Snowball Edge is **no longer available to new customers**. The Storage Optimized device has 210 TB of usable capacity. For new customers, AWS suggests DataSync for online transfers, **AWS Data Transfer Terminal** for physical transfers (bringing storage devices to an AWS facility; currently available only to Enterprise Support customers), or an AWS Partner solution.

<Takeaway>Bandwidth is sufficient: DataSync (can transfer privately over Direct Connect + a VPC endpoint). Data beyond what the link can handle: physical shipping (Snowball Edge for existing customers; Data Transfer Terminal or an AWS Partner for new customers), import into S3, then apply lifecycle or copy onward. SFTP: Transfer Family. Existing objects that must be copied to another Region: S3 Batch Replication.</Takeaway>

</Scene>
