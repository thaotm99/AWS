# S3 — Study Notes

## Concepts đã thảo luận

### 1. Buckets & Objects
- Bucket là **regional** nhưng tên phải **globally unique** (shared global namespace)
- Không có khái niệm "folder" thực sự — chỉ là key với slash (`/`)
- Key = prefix + object name (full path)
- Max object size: **5TB** — upload >5GB bắt buộc dùng **Multipart Upload**
- Version ID tồn tại khi versioning bật; file cũ trước khi bật = version `null`

### 2. Security Model
```
IAM principal access S3 khi:
  (IAM policy ALLOW  OR  Resource policy ALLOW)
  AND  (không có explicit DENY)
```
- **Bucket Policy**: JSON, áp dụng cross-account, public access
- **ACL** (Object/Bucket): ít dùng, có thể disable
- **Block Public Access**: account-level override — luôn bật nếu bucket không cần public
- Bucket Policy được đánh giá **trước** Default Encryption

### 3. Versioning & Replication
- Replication (CRR/SRR): chỉ replicate object **mới** sau khi bật — object cũ dùng **S3 Batch Replication**
- Delete marker: **không** replicate khi xóa theo version ID (tránh malicious delete)
- Không có "chaining": Bucket1 → Bucket2 → Bucket3, object từ Bucket1 **không** tự lên Bucket3
- CRR use case: compliance, lower latency, cross-account
- SRR use case: log aggregation, prod↔test sync

### 4. Storage Classes
| Class | Availability | Min duration | Retrieval | Ghi chú |
|---|---|---|---|---|
| Standard | 99.99% | — | Instant | Default |
| Standard-IA | 99.9% | 30 days | Instant | DR, backup |
| One Zone-IA | 99.5% | 30 days | Instant | Data có thể recreate |
| Glacier Instant | 99.9% | 90 days | Milliseconds | Access 1 lần/quý |
| Glacier Flexible | 99.99% | 90 days | 1–12 hours | Expedited/Standard/Bulk |
| Glacier Deep Archive | 99.99% | 180 days | 12–48 hours | Long-term archive |
| Intelligent-Tiering | 99.9% | — | Varies | Auto-move, không có retrieval fee |
| Express One Zone | 99.95% | — | Single-digit ms | HPC, ML training, 10x faster |

**One Zone-IA**: dữ liệu mất nếu AZ bị destroy → chỉ dùng cho **re-creatable data**

### 5. Lifecycle Rules
- **Transition Actions**: chuyển storage class theo thời gian (prefix hoặc tag)
- **Expiration Actions**: tự xóa sau N ngày (log files, incomplete multipart, old versions)
- Minimum storage duration charge vẫn tính dù chuyển sớm hơn (Standard-IA = 30 ngày, Glacier = 90 ngày)

### 6. Performance
- Baseline: **3,500 PUT/s** và **5,500 GET/s per prefix** — không giới hạn số prefix
- Spread prefix → multiply throughput tuyến tính
- **Multipart Upload**: khuyến nghị >100MB, bắt buộc >5GB
- **Transfer Acceleration**: upload qua Edge Location → private AWS network → S3 đích (giảm latency upload cross-region)
- **Byte-Range Fetches**: parallelize GET, chỉ lấy phần cụ thể của file

### 7. Event Notifications
- Trigger: `S3:ObjectCreated`, `S3:ObjectRemoved`, `S3:ObjectRestore`...
- Đích trực tiếp: **SNS, SQS, Lambda** (cần resource policy trên đích)
- Qua **EventBridge**: filter phức tạp hơn, 18+ đích, hỗ trợ Archive & Replay

### 8. Encryption — 4 loại
| Type | Key quản lý | Header | Ghi chú |
|---|---|---|---|
| SSE-S3 | AWS | `x-amz-server-side-encryption: AES256` | Default cho bucket mới |
| SSE-KMS | AWS KMS | `x-amz-server-side-encryption: aws:kms` | Audit được qua CloudTrail |
| SSE-C | Customer | HTTPS bắt buộc, key trong mỗi request | S3 không lưu key |
| Client-Side | Customer hoàn toàn | — | Encrypt trước khi gửi |

**SSE-KMS caveat**: mỗi upload/download gọi KMS API → có thể bị throttle (5,500–30,000 req/s tùy region)

### 9. CORS
- Bucket B cần set `Access-Control-Allow-Origin` = domain Bucket A
- Phổ biến: static website ở bucket A gọi assets từ bucket B

### 10. MFA Delete
- Bắt buộc MFA khi: **xóa version vĩnh viễn** hoặc **suspend versioning**
- Không cần MFA khi: enable versioning, list deleted versions
- Chỉ **root account** mới enable/disable được; versioning phải bật trước

### 11. Pre-Signed URLs
- User nhận URL **thừa hưởng permission của người tạo** (GET hoặc PUT)
- Expiry: Console max 12h, CLI max 168h (7 ngày)

### 12. S3 Object Lock & Glacier Vault Lock
| | S3 Object Lock | Glacier Vault Lock |
|---|---|---|
| Model | WORM per object | WORM toàn vault |
| Compliance mode | Không ai xóa được kể cả root | Policy không đổi được sau khi lock |
| Governance mode | Một số user đặc quyền có thể thay đổi | — |
| Legal Hold | Độc lập với retention period | — |

### 13. Access Points & Object Lambda
- **Access Points**: mỗi point có DNS + policy riêng → đơn giản hóa bucket policy phức tạp
- **VPC Origin Access Point**: chỉ accessible trong VPC → cần VPC Endpoint
- **S3 Object Lambda**: transform object on-the-fly khi read (redact PII, resize image, convert format)

## Key insights

- **Prefix = throughput unit**, không phải bucket — đây là điểm hay bị nhầm nhất
- **One Zone-IA chỉ dùng cho re-creatable data** — dữ liệu gốc không thể mất
- **Replication không retroactive** — object cũ cần Batch Replication riêng
- **Bucket Policy evaluate trước Default Encryption** — dùng Bucket Policy để force SSE-KMS
- **SSE-KMS có thể gây throttle** ở high-throughput workload → cân nhắc SSE-S3 hoặc tăng KMS quota
- **Snowball không import trực tiếp vào Glacier** — phải qua S3 trước, rồi dùng Lifecycle

## So sánh với services liên quan

| So sánh | S3 | EFS | EBS |
|---|---|---|---|
| Type | Object storage | NFS file system | Block storage |
| Access | HTTP/S | Mount (NFS) | Mount (OS) |
| Multi-AZ | Có (default) | Có (Standard) | Không (1 AZ) |
| Use case | Static files, backup, data lake | Shared filesystem, containers | OS disk, DB |

**CloudFront vs S3 CRR:**
- CloudFront: cache tại edge, TTL-based, global, static + dynamic
- S3 CRR: replicate object thực sự, near real-time, chỉ read, vài region cụ thể

## Exam tips đúc kết

1. **"immediately accessible" + "re-creatable"** → One Zone-IA (không phải Glacier)
2. **Throughput issue** → spread prefix, không tạo bucket mới
3. **Cross-account S3 access** → Bucket Policy (resource-based), không phải IAM policy đơn thuần
4. **Encrypt existing unencrypted objects** → S3 Batch Operations
5. **"audit key usage"** trong câu hỏi encryption → SSE-KMS (vì CloudTrail log KMS API calls)
6. **Force HTTPS** → Bucket Policy với `aws:SecureTransport: false` → Deny
7. **Delete marker không replicate** khi xóa theo version ID — tránh malicious delete
8. **Snowball → Glacier**: phải qua S3 + Lifecycle, không trực tiếp
9. **MFA Delete** chỉ root account mới bật được
10. **Pre-signed URL**: người nhận có quyền của người **tạo** URL, không phải của chính họ
